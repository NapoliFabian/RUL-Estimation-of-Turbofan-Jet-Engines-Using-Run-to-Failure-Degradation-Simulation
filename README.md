# RUL Estimation of Turbofan Engines Using Change Point Detection Technique
This paper address the critical problem of Remaining Useful Life (RUL) estimation for turbofan jet engines. Traditional approaches, as seen in [1] and [2], use static labeling techniques, such as piecewise functions obtained by truncating the maximal RUL or linear degradation towards zero. We propose a novel dynamic labeling approach based on change point detection in sensor data, using Principal Component Analysis (PCA) to fuse sensor values and reveal clear patterns. Our strategy is to identify significant shifts in sensor patterns, using these change points as for RUL labelling. Then different models were trained to estimate the RUL using the new proposed approach. Experimental results demonstrate that applying machine learning algorithms to this new dynamic labeling strategy yields superior performance compared to previously proposed techniques.
