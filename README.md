#RUL Estimation of Turbofan Engines Using Change Point Detection Technique
This paper addresses the critical problem of Remaining Useful Life (RUL) estimation for turbofan jet engines. Traditional approaches, as seen in [1] and [2], rely on static labeling of the dataset to train machine learning models for RUL estimation. We propose a novel dynamic labeling approach based on change point detection in sensor data. Our strategy is to identify significant shifts in sensor patterns, using these change points for RUL labelling. Then machine learning algorithms were used to estimate the RUL using the new proposed approach. Experimental results demonstrate that applying machine learning algorithms to this new dynamic labeling strategy yields better performance compared to the previously proposed techniques
